# Opper

[Opper](https://opper.ai) is an EU-hosted AI gateway. One API key gives you access to 700+ models from 50+ providers behind one OpenAI-compatible API. The Opper provider for the AI SDK sends each request to the Opper gateway, which routes it to a provider that serves the model.

It supports text generation, streaming, tool calls, and embeddings.

## Setup

The Opper provider is available in the [`@opperai/ai-sdk-provider`](https://www.npmjs.com/package/@opperai/ai-sdk-provider) package. Install it with:

<InstallPackages packages="ai @opperai/ai-sdk-provider" />

Create an API key in the [Opper platform](https://platform.opper.ai) and set it in your environment:

```bash
OPPER_API_KEY=your_api_key
```

## Provider Instance

The package exports a default `opper` provider. It reads `OPPER_API_KEY` from the environment:

```ts
import { opper } from '@opperai/ai-sdk-provider';
```

Use `createOpper` when you want to pass the key or base URL explicitly:

```ts
import { createOpper } from '@opperai/ai-sdk-provider';

const opper = createOpper({
  apiKey: process.env.OPPER_API_KEY,
  baseURL: 'https://api.opper.ai/v3/compat', // default
});
```

`createOpper` also accepts custom `headers` and a custom `fetch` implementation.

## Language Models

Call the provider with an Opper model ID to create a language model:

```ts
const model = opper('claude-sonnet-4-6');
```

Opper model IDs come in two forms:

- **Pool names** such as `claude-sonnet-4-6`, `gpt-5.5`, or `gemini-3.8-flash`. A pool covers every provider that serves the model, and Opper picks the route for each request.
- **Pinned routes** in `provider/model` form, such as `anthropic/claude-sonnet-4-6`. These always use the named provider.

To switch models, change the model ID:

```ts
const claudeModel = opper('claude-sonnet-4-6');
const gptModel = opper('gpt-5.5');
const geminiModel = opper('gemini-3.8-flash');
const deepseekModel = opper('deepseek-v4-pro');
const pinnedModel = opper('anthropic/claude-sonnet-4-6');
```

Browse the available models in the [Opper model catalog](https://opper.ai/models). The catalog is also published as the [`opper` provider on models.dev](https://models.dev/providers/opper/).

## Embedding Models

Use `opper.embeddingModel` to create an embedding model:

```ts
const embeddingModel = opper.embeddingModel('text-embedding-3-small');
```

## Examples

### `generateText`

```ts
import { opper } from '@opperai/ai-sdk-provider';
import { generateText } from 'ai';

const { text } = await generateText({
  model: opper('claude-sonnet-4-6'),
  prompt: 'What is an AI gateway?',
});

console.log(text);
```

### `streamText`

```ts
import { opper } from '@opperai/ai-sdk-provider';
import { streamText } from 'ai';

const result = streamText({
  model: opper('gpt-5.5'),
  prompt: 'Write a short story about a lighthouse keeper.',
});

for await (const textPart of result.textStream) {
  process.stdout.write(textPart);
}
```

### `embed`

```ts
import { opper } from '@opperai/ai-sdk-provider';
import { embed } from 'ai';

const { embedding } = await embed({
  model: opper.embeddingModel('text-embedding-3-small'),
  value: 'What is an AI gateway?',
});

console.log(embedding);
```
